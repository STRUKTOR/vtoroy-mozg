# Второй мозг

Шаблон личной базы знаний для Claude по идее Андрея Карпаты. Вы складываете материалы во «Входящие», Claude раскладывает их по страницам и отвечает по ним. База живёт в вашем приватном репозитории на GitHub и сама синхронизируется.

Учебный курс «Claude в работе», Struktor.

## Как завести себе

Нужно: приложение Claude (вкладка Code) и GitHub, подключённый к Claude (git, gh, вход). Во вкладке Code, сессия в вашей рабочей папке:

```
Заведи мне второй мозг из шаблона STRUKTOR/vtoroy-mozg: приватный репозиторий moy-mozg на моём GitHub и папка moy-mozg в текущей папке.
```

Полный промпт с проверками: в материалах курса. Потом откройте папку `moy-mozg` новой сессией.

## Фразы

| Фраза | Что делает Claude |
|---|---|
| обработай входящие | новые файлы раскладывает по страницам, обновляет Оглавление и Журнал |
| вопрос по базе: … | отвечает по страницам и называет их; нет в базе: так и говорит |
| запомни в базе: … | дописывает факт на нужную страницу |
| проверь базу | противоречия, устаревшее, обещания без отчёта: списком, сам не исправляет |

## Что внутри

- `Входящие/`: кладёте вы, Claude только читает
- `Страницы/`: ведёт Claude, одна тема на страницу
- `Оглавление.md`, `Журнал.md`
- `CLAUDE.md`: правила базы
- `.claude/settings.json`: хуки синхронизации. В начале сессии база подтягивается с GitHub, в конце каждого ответа изменения сохраняются на GitHub
- `Учебное/`: четыре учебные планёрки вымышленной компании «Пример-Кабель». После курса можно удалить: «Убери из базы всё учебное»
